# CNN Practice

이 리포지토리는 CNN(Convolutional Neural Network) 학습 및 실습을 위한 프로젝트입니다.

## 프로젝트 구조
- `src/`: 소스 코드
- `data/`: 데이터셋
- `models/`: 학습된 모델 저장
- `notebooks/`: Jupyter 노트북

## 환경 설정
- Python 3.8+
- PyTorch
- NumPy
- Matplotlib

## 설치 방법
```bash
pip install -r requirements.txt
```

## 사용 방법
1. 데이터셋 준비
2. 모델 학습
3. 결과 시각화
